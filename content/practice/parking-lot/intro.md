**The prompt:** *"Design a parking lot."* That's all the interviewer says. You have about 45 minutes.

This is the most-asked LLD question. It is not hard, which is why the bar is high: interviewers expect clean requirements, a small class model without needless inheritance, clear park/unpark flows, swappable pricing and allocation, and a correct answer on concurrency.

You'll go through it the same way you would in a real interview:

| Phase | Interview time |
|---|---|
| Clarify requirements | 3–5 min |
| Entities, class diagram | 8–10 min |
| Core flows | 5 min |
| Extensibility and concurrency | 8 min |
| Code | 15 min |
| Follow-ups | 5 min |

> Once you've finished this practice, do the **Parking Lot build-along**. It turns the same design into tested code, one step at a time.
