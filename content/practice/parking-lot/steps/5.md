The interviewer says: *"Weekends are a flat rate. We're adding EV chargers. And every floor gets a screen showing free spots."*

For each change, write:
- the **design pattern** you'd use
- the **interface** (one method signature is enough)
- **which existing classes change**. Ideally none.

## 1. Pricing → **Strategy**

```java
interface PricingStrategy { long fee(VehicleType type, Duration parked); }

class HourlyPricing implements PricingStrategy { /* rate × started hours, min 1 */ }
class FlatPricing   implements PricingStrategy { /* one price per visit */ }
class WeekendPricing implements PricingStrategy {   // picks one or the other
    WeekendPricing(PricingStrategy weekday, PricingStrategy weekend, Clock clock) { ... }
}
```

```go
type PricingStrategy interface {
	Fee(t VehicleType, parked time.Duration) int64
}
```

```python
class PricingStrategy(ABC):
    @abstractmethod
    def fee(self, vtype: VehicleType, parked: timedelta) -> int: ...
```

`WeekendPricing` *composes* two strategies. It's a small **decorator/composite**, and `ParkingLot` is untouched.

## 2. Spot allocation → **Strategy**

`SpotSelector.select(freeSpots, vehicle)`. `NearestSpotSelector` returns the first one. An `EvFirstSelector` prefers spots with chargers for EVs and otherwise delegates to another selector. EV-ness is **data** on `Spot` (`hasCharger`) and on `Vehicle` (`electric`). No subclass explosion.

## 3. Display boards → **Observer**

```java
interface ParkingListener { void onEvent(ParkingEvent e); }   // PARKED / FREED + spot
class DisplayBoard implements ParkingListener {
    private final Map<SpotSize, Integer> free = new EnumMap<>(SpotSize.class);
    public void onEvent(ParkingEvent e) { /* ±1 for e.spot().size() */ }
}
```

The lot publishes events. Boards, an analytics sink or an SMS alerter subscribe. The lot doesn't know who's listening.

## Open/Closed check

| Change | New class | Edited class |
|---|---|---|
| Weekend flat rate | `FlatPricing`, `WeekendPricing` | none (wiring only) |
| EV chargers | `EvFirstSelector` | `Spot` gains a `hasCharger` field |
| Floor screens | `DisplayBoard` | none |

> **Say:** *"Each of the three things you're likely to change sits behind an interface, so changes are additive."* That sentence is worth points.
