Design the `PlayQueue`. Write the algorithm (pseudocode is fine) for:

1. `next(repeat, auto)`, where `auto` = the song ended on its own vs. the user pressed Next
2. `previous()`, including "restart if more than 3s in"
3. `setShuffle(on)` and `setShuffle(off)`. The current song must keep playing, and turning shuffle off must return to the original order **at the same song**.

The queue may contain the same song twice.

<!-- answer -->

## Representation

```
songs: [A, B, C, A, D]     // as loaded, duplicates allowed
order: [0, 1, 2, 3, 4]     // indices into songs, i.e. the play order
pos:   2                   // cursor into order → current = songs[order[pos]] = C
```

Shuffle permutes **`order`**, never `songs`. Using **indices** (not song ids) is what makes duplicates and un-shuffling work.

## `next(repeat, auto)`

```
if pos < 0:                     return none          // empty queue
if auto and repeat == ONE:      return current        // replay the same song
if pos + 1 < len(order):        pos++
else if repeat != OFF:          pos = 0               // ALL wraps; a user skip under ONE wraps too
else:                           return none           // end of queue → player stops
return current
```

**Repeat ONE only affects the automatic advance.** If the user presses Next, they want the next song.

## `previous()`

```
if output.position > 3s:  restart current      // done in Player, which knows the position
else if pos > 0:          pos--
return current
```

## Shuffle on

```
cur  = order[pos]
rest = all indices except cur
fisherYates(rest)               // uniform random permutation, O(n)
order = [cur] + rest
pos = 0
```

The current song stays current, and everything else is randomised **once**. Calling `random()` on each `next()` instead would repeat songs and couldn't support "previous".

## Shuffle off

```
cur   = order[pos]
order = [0, 1, ..., n-1]
pos   = cur                     // same song, original position
```

## Complexity

`next`/`previous`/`current` are O(1). Shuffle toggles are O(n). "Add to queue" is an append to `songs` and `order`. "Play next" inserts into `order` at `pos + 1`.
