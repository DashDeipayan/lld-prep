If A owes B 30 from one dinner and B owes A 10 from a taxi ride, the app must say **A owes B 20**, and **B owes A 0**.

## Antisymmetric net map

Store a **signed** `net[a][b]`, meaning *a owes b*, and keep `net[b][a] = -net[a][b]` at all times:

```java
private void addDebt(String debtor, String creditor, long amount) {
    net.computeIfAbsent(debtor, k -> new HashMap<>()).merge(creditor, amount, Long::sum);
    net.computeIfAbsent(creditor, k -> new HashMap<>()).merge(debtor, -amount, Long::sum);
}

long owes(String debtor, String creditor) {
    return Math.max(0, net.getOrDefault(debtor, Map.of()).getOrDefault(creditor, 0L));
}
```

```go
func (s *Splitwise) addDebt(debtor, creditor string, amount int64) {
	s.row(debtor)[creditor] += amount
	s.row(creditor)[debtor] -= amount
}
```

## balance(user)

Net position: **positive** means others owe this user, **negative** means the user owes others.

`balance(u) = Σ over v of net[v][u]` (what everyone else owes `u`).

Invariant to mention (and the tests check it): **the sum of all balances is always 0.**
