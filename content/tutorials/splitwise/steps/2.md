Now the `Splitwise` service itself.

## Users

`addUser(id)`. A duplicate id is an error (Java `IllegalArgumentException`, Go `ErrDuplicateUser`).

## Expenses

```java
String addExpense(String paidBy, long amount, List<String> participants, Split split)
```

1. Validate: the payer and every participant exist (`ErrUnknownUser`). There are no duplicate participants and `amount > 0` (`ErrInvalidSplit`).
2. `shares = split.shares(amount, participants)`.
3. For every participant `p ≠ paidBy`: **p owes paidBy `shares[p]`**. The payer's own share is just what they spent on themselves.
4. Return ids `"E1"`, `"E2"`, …
