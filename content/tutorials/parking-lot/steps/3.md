Parking is where the first **Strategy** appears.

## The flow

```java
Ticket park(Vehicle v) {
    if (activeByPlate.containsKey(v.plate())) throw new IllegalStateException("already parked");
    List<Spot> candidates = free spots that canFit(v), in lot order;
    Spot spot = selector.select(candidates, v);          // strategy decides
    if (spot == null) throw new ParkingFullException();
    spot.occupy(v);
    Ticket t = new Ticket("T" + nextTicket++, v.plate(), spot.id(), clock.nowMillis());
    // remember ticket → spot, plate → ticket
    return t;
}
```

## SpotSelector: the strategy

```java
interface SpotSelector {
    /** candidates: free, fitting spots in lot order. Return null/nil if none is acceptable. */
    Spot select(List<Spot> candidates, Vehicle v);
}
```

`NearestSpotSelector` returns the **first** candidate: the lowest floor, then the smallest size that fits, then the lowest number. A bike takes a small spot before a medium one, which keeps big spots for big vehicles.

Because the lot only ever talks to the interface, tomorrow's "fill the top floor first" or "EV charging spots for EVs" is a new class. **Say that out loud in the interview.**

## Errors

- No spot available → Java `ParkingFullException` (provided), Go `ErrLotFull`
- The same plate is already inside → Java `IllegalStateException`, Go `ErrAlreadyParked`

Ticket ids are `T1`, `T2`, … in issue order. The entry time comes from the injected clock.
