Entrance displays show live free counts per size. Polling the lot is wasteful. Instead the lot **publishes events** and the board **observes** them.

## Events

After every successful park or unpark, notify all listeners **in the order they were added**:

```java
record Event(String kind, String ticketId, String spotId, SpotSize size) {}   // kind: "PARKED" or "LEFT"
```

```python
@dataclass(frozen=True)
class Event:
    kind: str  # "PARKED" or "LEFT"
    ticket_id: str
    spot_id: str
    size: SpotSize
```

`addListener(listener)` (Python `add_listener`) registers a `ParkingListener` with `onEvent(Event)` (Python `on_event`). Failed parks don't emit events.

## DisplayBoard

`new DisplayBoard(lot)` / `NewDisplayBoard(lot)` / `DisplayBoard(lot)`:

1. reads the **current** availability for each size from the lot
2. registers **itself** as a listener
3. keeps a counter per size: `PARKED` decrements, `LEFT` increments

`free(size)` returns the counter. The test checks it against `lot.available(size)` after a mixed sequence of parks and unparks.

```java
final class DisplayBoard implements ParkingListener {
    private final Map<SpotSize, Integer> free = new EnumMap<>(SpotSize.class);
    DisplayBoard(ParkingLot lot) {
        for (SpotSize s : SpotSize.values()) free.put(s, lot.available(s));
        lot.addListener(this);
    }
    public void onEvent(Event e) { free.merge(e.size(), e.kind().equals("PARKED") ? -1 : 1, Integer::sum); }
}
```

```python
class DisplayBoard(ParkingListener):
    def __init__(self, lot: ParkingLot) -> None:
        self._free = {s: lot.available(s) for s in SpotSize}
        lot.add_listener(self)

    def on_event(self, event: Event) -> None:
        self._free[event.size] += -1 if event.kind == "PARKED" else 1
```

**Design note:** notify listeners **after** the lot's state is updated. In the next step, notify them **outside** any lock.
