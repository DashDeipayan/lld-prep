Unparking returns a receipt, and the fee comes from the second **Strategy**.

## PricingStrategy

```java
interface PricingStrategy {
    long fee(VehicleType type, long durationMillis);
}
```

```python
class PricingStrategy(ABC):
    @abstractmethod
    def fee(self, vehicle_type: VehicleType, duration_ms: int) -> int: ...
```

`HourlyPricing(rates)`: `rates.get(type) × hours`, where `hours` is the number of **started** hours and is **at least 1**.

| Parked for | Hours charged |
|---|---|
| 0 min | 1 |
| 59 min | 1 |
| 60 min | 1 |
| 61 min | 2 |
| 3 h 0 min | 3 |

```java
long hours = Math.max(1, (durationMillis + 3_599_999) / 3_600_000);   // ceil, min 1
```

```go
hours := int64((d + time.Hour - 1) / time.Hour)
if hours < 1 {
	hours = 1
}
```

```python
hours = max(1, -(-duration_ms // 3_600_000))  # ceiling division, min 1
```

## Unpark

```java
Receipt unpark(String ticketId) {
    Ticket t = active.remove(ticketId);                    // unknown or already used → error
    Spot spot = spotsById.get(t.spotId());
    Vehicle v = spot.vacate();
    long duration = clock.nowMillis() - t.entryMillis();
    return new Receipt(t.id(), t.plate(), spot.id(), duration / 60_000, pricing.fee(v.type(), duration));
}
```

```python
def unpark(self, ticket_id: str) -> Receipt:
    t = self._active.pop(ticket_id, None)  # unknown or already used -> error
    if t is None:
        raise ValueError("unknown ticket " + ticket_id)
    spot = self._spots_by_id[t.spot_id]
    v = spot.vacate()
    duration = self._clock() - t.entry_ms
    return Receipt(t.id, t.plate, spot.id, duration // 60_000, self._pricing.fee(v.type, duration))
```

An unknown or already-used ticket is an error (Java `IllegalArgumentException`, Go `ErrUnknownTicket`, Python `ValueError`). After unparking, the same plate can park again.

> **Follow-up you'll get:** *"weekend pricing is 1.5×"*. That's a `WeekendPricing` that wraps another `PricingStrategy` (Decorator), or a new strategy. `ParkingLot` doesn't change.
