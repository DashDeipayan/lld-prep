Start with the smallest building block, the **spot**. It knows its id, floor and size, whether a vehicle fits, and who is parked in it.

## Fitting rules

| Vehicle | SMALL | MEDIUM | LARGE |
|---|---|---|---|
| BIKE | ✓ | ✓ | ✓ |
| CAR | | ✓ | ✓ |
| TRUCK | | | ✓ |

A neat way to express this without a `switch`: give each enum an ordinal "rank" and say *a vehicle fits if `spot.size ≥ vehicle.minimumSize`*.

```java
// in VehicleType (provided): BIKE(SpotSize.SMALL), CAR(SpotSize.MEDIUM), TRUCK(SpotSize.LARGE)
boolean canFit(Vehicle v) {
    return size.compareTo(v.type().minSize()) >= 0;
}
```

```go
// VehicleType.MinSize() is provided: Bike→Small, Car→Medium, Truck→Large
func (s *Spot) CanFit(v Vehicle) bool { return s.size >= v.Type.MinSize() }
```

## Occupancy

- `occupy(v)` parks `v`. Fail if the spot is occupied **or** `v` doesn't fit (Java: `IllegalStateException` / Go: `ErrSpotUnavailable`)
- `vacate()` frees it. Return the vehicle that left (Java `Vehicle`, Go `(Vehicle, bool)`)
- `isFree()` reports whether the spot is empty

**Why does the spot validate this itself?** Encapsulation: the invariant "one fitting vehicle per spot" lives with the data, so no caller can break it.
